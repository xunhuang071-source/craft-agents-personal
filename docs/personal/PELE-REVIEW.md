# Pele 与展开批注：正式版验收

正式版本：**wallee-v1.1.0**。来源候选为 wallee-v1.1.0-rc.1；用户已于 2026-10-29 手动安装并确认显示和批注效果满意。正式晋升只更新版本管理记录，不重建或替换已验收程序。

## 改动

- 显示、编辑器图型识别和主进程 Mermaid 校验统一使用固定版本 `pele@1.12.0`。移除主源码依赖中的 beautiful-mermaid、elkjs 及相关旧引擎分支。
- Pele 只生成 SVG；App 保留一套缩放、平移、选字和批注交互，不使用 Pele mount/zoom。
- 普通消息、MD 全文和其中二次展开的图表复用同一批注组件及原消息保存回调。图内文字可直接选中、输入和保存，无需关闭图表。
- 图表浮层使用统一 Radix 模态和关闭栈；批注菜单及遮罩挂到当前 dialog 的非裁剪区域。
- 选字不再自动打开图表；拖动空白可平移。平移的 mouseup 在 capture 阶段结束，避免浮层隔离事件后仍跟随鼠标。
- Escape 每次只处理当前交互层；取消不保存内容，关闭不在底层补弹菜单。
- 新批注补充图表块、源码指纹和 SVG 标签局部锚点。旧数字偏移须核对原文；引用唯一时可恢复位置，重复且无法唯一定位时明确显示未定位，不误贴。
- 不读取或迁移真实历史消息，不更改批注 schema 版本；继续使用原有 AnnotationV1 metadata 与保存回调。

## 冻结 Pi 包中的静态残留

两个 Pi bundle 按批准边界保持原哈希，因上游静态打包仍含旧校验器代码。**它们不作为第二套活动引擎，也没有旧引擎回退路径。** 实际会话工具注册使用主进程代理；本次分别启动两个原 bundle，以本地模型模拟调用 Mermaid 校验，均证明请求交给主进程 Pele，且 Pele 新图型校验成功。

本次不为清除不可达静态字节而重建冻结 Pi。若后续要求包内彻底没有旧库代码，需要单独批准 Pi bundle 清理与回归；不能把本次结果描述为“整个应用每一字节都不含旧库”。

## 兼容口径

- Pele 使用自己的布局，旧图的节点位置、间距和线条会变化，不承诺像素一致。
- 适配 App 明暗主题和中文字体；保留源码方向。任意 HTML 标签、JavaScript 回调及 Mermaid themeVariables 不保证等价。
- 新增批注依靠块与标签局部锚点。历史批注无法唯一恢复时提示未定位；不改写原记录，不猜测位置。
- 未进行真实账户登录、真实模型联网调用或用户数据迁移。未自动替换、关闭或重启当前安装版；未声称完成整个产品的全量回归。
- 应用内部的上游 0.14.1 标识与身份保持原样，个人正式版本见组件锁和 Release 清单。

## 构建与回退

按照 [维护手册](MAINTENANCE.md) 的“图表定点更新”流程构建；入口为 [personal-build-diagram-candidate.mjs](../../scripts/personal-build-diagram-candidate.mjs)。源码、依赖锁、基线锁、组件锁和测试共同维护。

验收时重点操作：打开一篇包含 Mermaid 的 MD → 展开图表 → 选中文字 → 写批注并保存 → 关闭图表，检查原文中索引和文字对应。取消与连续 Escape 不应误关底层文档。

当前用户已安装对应的验收代码，无需再次安装。需要回退时仅换回 wallee-v1.0.0 应用，不恢复旧对话快照。记录会保留；新批注在旧绘图布局中的显示位置需重新核对。
