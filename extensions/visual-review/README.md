# Craft 视觉审阅

工作台在本机运行，用 Craft 内置浏览器打开。每次交付图片或 HTML，默认附上直接选中该文件的「进入批注」链接。

```bash
cd tools/visual-review
npm ci --ignore-scripts --omit=optional
node server.mjs /path/to/project/review /path/to/image.png /path/to/page.html
```

命令输出地址。为各文件分别生成 `?asset=0`、`?asset=1` 等直达链接，序号对应命令中的文件顺序。发送前检查链接可访问。服务关闭后重新运行命令，以新地址打开；原反馈及草稿留在指定目录。

## 使用

- 图片默认「涂抹选区」，还可切换矩形、点位。笔刷大小按屏幕显示像素设置，存储时转换为原图像素。
- 涂抹选中覆盖区域；「擦除选区」扣除部分；支持撤销、重做、清空和显示/隐藏。多笔可构成同一区域，允许孔洞和分离区域；沿边描一圈不自动填满。
- HTML 默认「选择文字」，可拖选几个字、一句话或跨节点文本；「点选元素」保留整元素批注。切换涂抹、矩形或点位后，可以对页面图形做批注。
- 每个选区填写修改要求，再点「加入批注」。不同要求分成不同条目。列表的「编辑」可重新打开文字要求或区域继续修边。
- 草稿自动保存在本机，也可以手动保存。页面重新打开后恢复本版文件的草稿与笔画；原文件版本变化后不会套用旧版草稿。
- 点「保存并生成回传指令」，再复制指令到当前 Craft 对话。当前仍需用户发送这一步。

## 定位与版本

反馈 JSON 的 schemaVersion 2 兼容旧点位数据，关联原文件路径及 SHA-256。

图片 region 保存原图宽高、原像素坐标下的笔画操作、bbox、selectedPixels 和两个独立文件：

- maskPath：原尺寸 PNG，白色选中、黑色未选中。阈值为笔画覆盖 alpha>=128。
- markupPath：同尺寸透明 PNG，显示半透明红色选区，供视觉核对。

界面显示透明度不代表选择强度。重复涂抹按覆盖区域取并集；擦除只影响蒙版。服务端重新解码并验证尺寸、空选区与原图版本。

HTML 的 text-range 保存 selector、原文 quote、文本节点相对 body 的 childNodes 路径、UTF-16 起止偏移、前后文和视口。一个批次可同时含文字与区域意见。修改前核对原文件版本与原文，不能只凭相同的短词全局替换。

HTML region/point 的坐标空间为 html-document，记录固定预览视口及命中的图形元素。内嵌图片同时提供自然尺寸、bbox、object-fit 和 object-position。转为内嵌图片编辑时需处理缩放和裁剪；整页蒙版不能直接套到图片上。

## 修改与交付

读取回传 JSON → 核对 SHA-256 → 检查文字或蒙版 → 修改并保存新文件 → 打开新版工作台 → 附上「进入批注」链接。

图片生成入口：工作区 `skills/craft-imagegen/scripts/image_bridge.py`。`edit --mask <白选黑不选PNG>` 表示区域引导；要求选区外完全保持时加 `--strict-mask`，本地合成，输出尺寸不一致时停止。Codex 订阅使用干净原图和区域参考图；OpenAI API 转换为接口蒙版。API 真机验收取决于指定凭据。

HTML 自包含静态文件可直接预览，保留内联样式和 data 图片；业务脚本、外部网络资源仍不执行。Canvas 内文字仍按图形处理。当前预览固定为 900×680 视口；区域蒙版覆盖文档尺寸，最多 3200 万像素。更大的页面请拆分后审阅。

## 实现参考

画面底层使用 Fabric.js；区域蒙版用独立 Canvas 2D 层，以 source-over 增选、destination-out 擦除。原图层保持不变。共用 RegionEditor 同时运行于图片与隔离 HTML 页面，减少重复实现。

参考 Fabric 自由画笔机制、Label Studio 的像素选区与原尺寸关联设计，未引入整套标注平台或额外后台服务。PNG 文件使用 pngjs 解码校验。
