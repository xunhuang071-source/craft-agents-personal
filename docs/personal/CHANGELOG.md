# 个人版版本日志

版本号独立于官方。应用内部的 0.14.1 标识不代表个人改造未生效。每个正式版必须有源码提交、引擎提交、安装包与校验清单。

## wallee-v1.1.0-rc.1 — 本地候选，2026-10-29

- 经明确批准定点更新 renderer 和主进程 Mermaid 校验，采用 `pele@1.12.0` 一套活动绘图引擎；编辑器图型检测同步使用 Pele。
- App 统一管理缩放、平移、选字和批注，不启用第二套缩放，不配置旧引擎回退。
- 修复 MD 二次展开图表不能原地选字批注、菜单裁剪/遮挡及关闭后底层补弹；补充图表块与标签锚点、历史原文核验和歧义保护。
- 修复空白平移 mouseup 被浮层隔离、保存后父窗口重新入栈和 Escape 重复消费等关联问题。
- 原 Pi、Antigravity Pi、两个 preload、interceptor、应用身份和数据位置保持不变。Pi 内上游静态旧代码保留但不参与活动校验，两个真实子进程代理测试均已验证。
- 120 项定点测试、2 项真实 Pi 代理测试及 8 组 Chromium 交互回归通过；三项 TypeScript 检查通过。详细范围和限制见 [验收记录](PELE-REVIEW.md)。
- 仅本地候选，不自动安装，不关闭当前应用，不上传或发布 Release。

## wallee-v1.0.0 — 2026-10-26

首个纳入完整个人版本管理的版本；对应用户当日已安装、确认可用的程序。本次版本归档不再次安装。

### 新增
- macOS 原生 Antigravity 菜单，应用管理固定版本 CLIProxyAPI v8.0.13。
- Google 授权、连接状态、模型刷新与独立凭据生命周期。
- 独立 Pi SDK 1.1.0 / v0.15.1 适配器；原有连接继续使用原路径。
- 源码、冻结资源、构建工具与发布包的对应记录。

### 保留
- v0.14.1 renderer、两个 preload、原 Pi 1.1 bundle、网络拦截器与原应用身份。
- v0.15.1 选择性后端移植：浏览器控制、任务运行与 MCP 资源/提示词接线等。
- GPT-6.1 Sol 登记及 500K 上下文、v0.15.6 MCP oauthRelay 与 sources.md 增补。
- 原有模型配置、默认模型、密钥及历史仍从本机原位置读取；不导入验证版资料。
- 官方自动更新保持禁用。

### 构建与验证
- Bun 1.3.9、esbuild 0.25.12；按仓库根目录命令重建，主程序与新适配器均已与安装文件逐字节核对一致。
- 本轮源码关键测试：主程序 121 通过、1 项原生二进制 opt-in 跳过；隔离服务 6 通过；引擎 169 通过、3 项子进程 opt-in 跳过。
- 实际已构建子进程的本地模拟集成测试另行运行：3/3 通过（工具、图片结构、429 不重放、取消）。完整候选重新组装、冻结资源和签名核对通过。敏感信息检查与安装包校验结果见 Release 附件；不将跳过算通过。
- 冻结资源和精确输出哈希见 personal-release.json；主程序提交、引擎提交、安装包哈希见 Release 的 release-manifest.json。

### 存储与部署
- 撤除本次全量备份/恢复演练工具和旧复杂安装器。约 14 GB 全量数据备份从未生成。
- 普通更新：退出程序，覆盖应用，重新打开验收。不复制个人数据，不使用旧快照覆盖新对话。
- 程序历史包放私有 Release，不把依赖、安装包、测试profile或真实账户资料放入 Git。
